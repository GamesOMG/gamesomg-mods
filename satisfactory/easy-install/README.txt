GamesOMG Teleport {VERSION} for Satisfactory: Easy Install
Guide: https://gamesomg.com/satisfactory-teleport-mod/

INSTALL
1. Open your Satisfactory folder: the one with FactoryGame, Engine and the game's .exe in it.
   Steam: right-click Satisfactory, Manage, Browse local files.
   Epic: Library, the three dots on Satisfactory, Manage, then the folder icon beside Installation.
2. Open this zip, select everything in it (Ctrl+A) and drag it onto an empty spot in that folder's window.
   Windows asks for permission: Continue. Windows asks to replace files: you already have SML, choose Skip.
   You now have FactoryGame\Mods\SML and FactoryGame\Mods\GamesOMGTeleport.
3. Start the game, load a world, press F9. F10 takes you back.

Satisfactory Mod Manager can't install this mod yet, and you don't need it. Already run mods with it? It has put SML
in FactoryGame\Mods\SML for you: take Satisfactory-GamesOMG-Teleport-{VERSION}-Windows.zip instead and unzip it into
FactoryGame\Mods\GamesOMGTeleport, so your SML stays the version the manager chose.

Remove it: delete FactoryGame\Mods\GamesOMGTeleport. Delete FactoryGame\Mods\SML too if you run no other mods.
